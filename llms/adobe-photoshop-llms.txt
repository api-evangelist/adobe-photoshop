# Adobe Photoshop

> Adobe Photoshop is the industry-standard image editing and digital design application. Its developer platform offers a cloud-based REST API for programmatic image processing via Firefly Services, the UXP plugin framework for building desktop extensions with modern JavaScript, a C++ plugin SDK for native filters and file formats, and scripting interfaces for workflow automation.

This llms.txt is generated by API Evangelist from the apis.json index and captured artifacts in the adobe-photoshop repo. All operations on the cloud API are asynchronous (submit → poll a status URL). Authentication is Adobe IMS: an `Authorization: Bearer <token>` (OAuth server-to-server / client_credentials) plus an `x-api-key` client-ID header.

## APIs

- [Adobe Photoshop API](https://developer.adobe.com/firefly-services/docs/photoshop/): Cloud REST API (base https://image.adobe.io) for background removal, mask creation, PSD document operations, Smart Object replacement, text editing, renditions, Photoshop Actions, product crop, depth blur, and generative fill. Current version v2 (v1 end-of-life 2026-07-31).
- [Adobe Firefly Services SDK for JavaScript](https://developer.adobe.com/firefly-services/docs/guides/sdks/): Typed Node.js/TypeScript client (@adobe/photoshop-apis) for the Photoshop API.
- [Adobe Photoshop UXP Plugin API](https://developer.adobe.com/photoshop/uxp/2022/): Modern desktop plugin platform (V8 JavaScript, HTML/CSS, Spectrum UI, DOM API).
- [Adobe Photoshop UXP Scripting](https://developer.adobe.com/photoshop/uxp/2022/scripting/): Standalone .psjs JavaScript automation.
- [Adobe Photoshop UXP Hybrid Plugins](https://developer.adobe.com/photoshop/uxp/2022/guides/hybrid-plugins/): UXP UI + native C++ (.uxpaddon).
- [Adobe Photoshop C++ Plugin SDK](https://developer.adobe.com/photoshop/): Native SDK for filters, file formats, selections, automation.
- [Adobe Photoshop ExtendScript Scripting API](https://extendscript.docsforadobe.dev/): Legacy .jsx ECMAScript 3 automation.
